# 주식 뉴스 시황 분석 대시보드 - 개발기획서

> 작성일: 2026-04-10
> 버전: v1.0

---

## 1. 프로젝트 개요

### 1.1 서비스 명
**StockLens** — 내 종목의 뉴스 시황을 AI가 매일 분석해주는 개인 투자 대시보드

### 1.2 한 줄 요약
관심 종목을 등록하면 국내외 주요 지수와 종목별 뉴스 시황을 AI가 매일 자동 분석·요약해주는 개인용 주식 대시보드

### 1.3 배경 및 필요성
- 주식 투자자는 매일 수십 개의 뉴스 기사를 수동으로 확인해야 함
- 국내외 지수 변동, 업종 동향, 개별 종목 이슈를 한 곳에서 파악하기 어려움
- AI를 활용한 뉴스 감성 분석으로 빠른 시황 파악이 가능함
- 개인 맞춤형 종목 관리와 일별 업데이트 자동화 수요 증가

## 3. 핵심 기능 목록

### 3.1 메인 대시보드

#### 국내외 종합주가지수 위젯
- **국내**: KOSPI, KOSDAQ, KRX 300
- **해외**: S&P 500, NASDAQ, Dow Jones, Nikkei 225, Shanghai Composite, FTSE 100
- 표시 정보: 현재지수, 전일 대비 등락폭, 등락률(%), 간이 차트(7일)
- 실시간 또는 15분 지연 데이터

#### 시장 요약 배너
- AI가 생성한 오늘의 시장 코멘트 (1~2문장)
- 업데이트 시각 표시

### 3.2 종목 검색 및 등록

#### 종목 검색
- 종목명 또는 티커 심볼 검색 (국내: 한국거래소, 해외: NYSE/NASDAQ)
- 자동완성(autocomplete) 지원
- 검색 결과: 종목명, 티커, 거래소, 현재가, 등락률

#### 관심 종목 등록
- 검색 결과에서 바로 관심 종목 추가
- 최대 20종목 등록 (개인 사용 기준)
- 등록 종목 그룹 관리 (예: 성장주, 배당주, 관망)

### 3.3 종목 상세 정보

#### 가격 정보
- 현재가, 시가, 고가, 저가, 거래량
- 52주 최고/최저
- 시가총액, PER, PBR, EPS (기본 재무지표)
- 캔들스틱 차트 (1일/1주/1달/3달)

#### AI 뉴스 시황 분석
- 최근 24~48시간 내 관련 뉴스 자동 수집
- Claude API 기반 감성 분석: 긍정 / 중립 / 부정 스코어
- 핵심 이슈 3줄 요약
- 뉴스 원문 링크 목록 (최대 10건)
- 분석 업데이트 시각 표시

### 3.4 매일 자동 업데이트

#### 스케줄러 (Python APScheduler / Celery)
- 평일 오전 8시: 전날 장 마감 후 뉴스 수집 및 AI 분석 실행
- 평일 오후 3시 30분: 장중 뉴스 중간 업데이트
- 주말: 글로벌 시장 주요 이슈 수집

#### 업데이트 내용
- 등록된 모든 종목의 뉴스 재수집
- AI 분석 결과 갱신
- 주요 지수 일일 변동 기록

### 3.5 알림 기능 (선택)
- 관심 종목 급등락 알림 (±5% 이상)
- 중요 뉴스 발생 시 브라우저 푸시 알림

## 4. 기술 스택

### 4.1 프론트엔드

| 항목 | 기술 | 선택 이유 |
|------|------|----------|
| 프레임워크 | Next.js 14 (App Router) | SSR/SSG로 SEO + 빠른 초기 로딩 |

| 데이터 페칭 | TanStack Query | 캐싱, 자동 갱신 |
| UI 컴포넌트 | shadcn/ui | 고품질 접근성 컴포넌트 |

### 4.2 백엔드

| 항목 | 기술 | 선택 이유 |
|------|------|----------|
| 프레임워크 | FastAPI (Python) | 비동기, AI 라이브러리 호환성 |
| 스케줄러 | APScheduler | 경량 스케줄링, 설정 간단 |
| 데이터베이스 | PostgreSQL | 안정성, JSON 지원 |
| ORM | SQLAlchemy + Alembic | Python 생태계 표준 |
| 캐싱 | Redis | 주가 데이터 캐싱 (15분) |

### 4.3 AI / 데이터

| 항목 | 기술 | 용도 |
|------|------|------|
| AI 분석 | Claude API (claude-sonnet-4-6) | 뉴스 감성 분석, 요약 |
| 주가 데이터 | Yahoo Finance API (yfinance) | 국내외 주가, 지수 |
| 국내 주가 | 한국투자증권 API 또는 FinanceDataReader | KOSPI/KOSDAQ 종목 |
| 뉴스 수집 | Google News RSS / Naver 금융 뉴스 | 종목별 뉴스 |
| 해외 뉴스 | NewsAPI 또는 RSS 파싱 | 영문 뉴스 |

### 4.4 인프라 (개인 사용 기준)

| 항목 | 기술 |
|------|------|
| 호스팅 | Vercel (프론트) + Railway/Render (백엔드) |

| 캐시 | Upstash Redis (무료 티어) |

## 6. 데이터베이스 스키마 (주요 테이블)

```sql
-- 관심 종목
stocks (
  id          UUID PRIMARY KEY,
  ticker      VARCHAR(20) NOT NULL,  -- 예: 005930, AAPL
  name        VARCHAR(100),
  exchange    VARCHAR(20),           -- KOSPI, NASDAQ 등
  market      VARCHAR(10),           -- KR, US
  created_at  TIMESTAMP
)

-- 주가 스냅샷 (일별)
price_snapshots (
  id          UUID PRIMARY KEY,
  stock_id    UUID REFERENCES stocks,
  date        DATE NOT NULL,
  open        DECIMAL,
  close       DECIMAL,
  high        DECIMAL,
  low         DECIMAL,
  volume      BIGINT,
  created_at  TIMESTAMP
)

-- AI 뉴스 분석 결과
news_analyses (
  id              UUID PRIMARY KEY,
  stock_id        UUID REFERENCES stocks,
  analysis_date   DATE NOT NULL,
  sentiment       VARCHAR(20),     -- positive / neutral / negative
  sentiment_score DECIMAL,         -- -1.0 ~ 1.0
  summary         TEXT,            -- AI 생성 3줄 요약
  key_issues      JSONB,           -- 핵심 이슈 목록
  news_sources    JSONB,           -- 원문 뉴스 링크 목록
  model_used      VARCHAR(50),     -- claude-sonnet-4-6 등
  created_at      TIMESTAMP
)

-- 지수 스냅샷
index_snapshots (
  id          UUID PRIMARY KEY,
  index_code  VARCHAR(20),        -- KOSPI, SP500 등
  date        DATE NOT NULL,
  value       DECIMAL,
  change      DECIMAL,
  change_pct  DECIMAL,
  created_at  TIMESTAMP
)
```

## 9. API 설계

| Method | 경로 | 설명 |
|--------|------|------|
| GET | `/api/v1/indices` | 전체 지수 목록 조회 |

## 10. AI 프롬프트 설계

### 뉴스 분석 프롬프트 (Claude API)

```
당신은 주식 시장 전문 애널리스트입니다.
다음은 [{종목명} ({티커})]에 관한 최근 뉴스 기사들입니다.

---
{뉴스 기사 목록 (최대 10개, 제목 + 본문 일부)}
---

다음 형식으로 분석 결과를 JSON으로 반환하세요:
{
  "sentiment": "positive | neutral | negative",
  "sentiment_score": -1.0 ~ 1.0 사이 숫자,
  "summary": ["핵심 이슈 1", "핵심 이슈 2", "핵심 이슈 3"],
  "reasoning": "감성 판단 근거 (1~2문장)"
}

규칙:
- 투자 조언이나 매수/매도 추천은 절대 포함하지 마세요
- 사실 기반으로만 분석하세요
- 한국어로 응답하세요
```
