## 1. 기능 개요 (Feature Overview)

### What
관심 종목을 등록하면 국내외 주요 주가지수와 종목별 뉴스 시황을 **Claude AI가 매일 자동 분석**해서 보여주는 개인용 주식 대시보드

### Why
- 주식 투자자는 매일 수십 개의 뉴스를 수동으로 확인해야 하는 피로 존재
- 국내외 지수 + 뉴스 + 감성 분석을 한 화면에서 확인할 수 없음
- AI 기반 자동 분석으로 시황 파악 시간을 90% 단축 가능

### Target User
- 주식 투자자 (개인, 소규모)
- 매일 관심 종목의 뉴스를 모니터링하는 사용자
- 국내(KOSPI/KOSDAQ) + 해외(NYSE/NASDAQ) 동시 관심 투자자

## 4. 사용자 스토리 (User Stories)

### Epic 1: 시장 현황 파악
```
US-01: 사용자로서, 홈 화면에서 KOSPI/KOSDAQ/S&P500 등 주요 지수를
       한눈에 보고 싶다. (지수명, 현재값, 등락률, 미니 차트)

US-02: 사용자로서, AI가 오늘의 전반적인 시장 분위기를 1~2문장으로
       요약해줬으면 한다.
```

### Epic 2: 종목 관리
```
US-03: 사용자로서, 종목명이나 티커로 검색하여 관심 종목을
       쉽게 추가하고 싶다.

US-04: 사용자로서, 등록한 종목 목록에서 현재가와 등락률을
       빠르게 확인하고 싶다.

US-05: 사용자로서, 종목을 그룹(성장주/배당주/관망)으로 분류하여
       관리하고 싶다.
```

### Epic 3: AI 뉴스 분석
```
US-06: 사용자로서, 관심 종목을 클릭하면 오늘 관련 뉴스에 대한
       AI 감성 분석 결과(긍정/중립/부정 스코어)를 보고 싶다.

US-07: 사용자로서, 뉴스 핵심 이슈를 3줄로 요약해서 빠르게
       파악하고 싶다.

US-08: 사용자로서, 원본 뉴스 링크를 클릭하여 상세 내용을
       확인하고 싶다.
```

### Epic 4: 자동 업데이트
```
US-09: 사용자로서, 매일 아침 출근 전(08:00)에 전날 장 마감 이후
       뉴스가 자동으로 분석되어 있기를 원한다.

US-10: 사용자로서, 마지막 업데이트 시각을 보고 데이터의
       신선도를 확인하고 싶다.
```

## 5. 기술 요구사항

### 프론트엔드 (Next.js 14)
| 항목 | 요구사항 |
|------|----------|
| 렌더링 | SSG(지수) + CSR(실시간 데이터) 혼합 |
| 차트 | TradingView Lightweight Charts (주가 캔들) |
| 상태관리 | Zustand (전역 상태) + TanStack Query (서버 상태) |
| UI | shadcn/ui + Tailwind CSS |
| 접근성 | WCAG 2.2 Level AA 준수 |

### 백엔드 (FastAPI)
| 항목 | 요구사항 |
|------|----------|
| 주가 데이터 | yfinance (15분 지연, 무료) |
| 국내 종목 | FinanceDataReader (KOSPI/KOSDAQ) |
| 뉴스 수집 | Google News RSS + Naver 금융 뉴스 RSS |
| AI 분석 | Claude API (claude-sonnet-4-6) |
| 스케줄러 | APScheduler (평일 08:00, 15:30) |
| 캐싱 | Redis (주가 15분, 뉴스 분석 24시간) |

### 데이터 저장
| 항목 | 요구사항 |
|------|----------|
| DB | PostgreSQL (Supabase) |
| 주요 테이블 | stocks, price_snapshots, news_analyses, index_snapshots |
| 이력 보관 | 뉴스 분석 결과 90일 보관 |

## 7. 개발 단계 (Phases)

```
Phase 1 — 기반 구축 (2주)
  ├── 프로젝트 셋업 (Next.js + FastAPI + Docker)
  ├── DB 스키마 설계 및 마이그레이션
  ├── yfinance 주가/지수 데이터 수집 API
  └── 기본 REST API 엔드포인트

Phase 2 — 핵심 UI (2주)
  ├── 메인 대시보드 레이아웃
  ├── 지수 위젯 컴포넌트
  ├── 종목 검색 + 관심 종목 CRUD
  └── 종목 상세 + 캔들스틱 차트

Phase 3 — AI 뉴스 분석 (2주)
  ├── 뉴스 RSS 수집 크롤러
  ├── Claude API 연동 + 프롬프트 설계
  ├── 감성 분석 결과 저장/표시
  └── APScheduler 자동 업데이트

Phase 4 — 완성도 (1주)
  ├── 모바일 반응형 최적화
  ├── Redis 캐싱 적용
  ├── 에러 처리 + 로딩 상태
  └── Vercel + Railway 배포
```
